# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/nextcloud.svg` | Default (light mode) |
| `icon-light.svg` | `svg/nextcloud-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/nextcloud-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/nextcloud.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/nextcloud-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/nextcloud-dark.svg
